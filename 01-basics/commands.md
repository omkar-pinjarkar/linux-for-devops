
# Linux Basics for DevOps

## What is Linux?
Linux is an open-source operating system widely used in servers,
cloud platforms, and DevOps environments.

## Why DevOps Engineers Use Linux
- Most cloud servers run Linux
- Lightweight and secure
- Powerful CLI automation
- Native support for DevOps tools

## Linux Architecture
- Kernel: Core of the OS
- Shell: Interface between user and kernel
- File System: Data storage structure

## Basic Linux Commands

### Navigation Commands
```bash
pwd        # Show current directory
ls         # List files
cd         # Change directory
```
### System Commands
```
whoami     # Current user
uname -a   # System information
history    # Command history
```
### Help Commands
```
man ls
ls --help
```
