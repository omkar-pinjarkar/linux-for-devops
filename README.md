# Linux for DevOps – From Basics to Advanced

This repository documents my learning of Linux from a DevOps perspective.
It includes commands, explanations, and real-world DevOps use cases.

## Why Linux for DevOps?
Linux is the backbone of cloud computing, CI/CD pipelines, containers,
and production servers. Every DevOps engineer must master Linux fundamentals.

## What You’ll Find Here
- Linux basics and architecture
- File and permission management
- User and process management
- Networking and storage
- Bash scripting
- Linux in DevOps tools like Docker and Jenkins

## Target Audience
- DevOps beginners
- Cloud engineers
- Students preparing for DevOps roles
